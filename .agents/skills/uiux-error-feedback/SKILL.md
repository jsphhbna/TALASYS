# Error Feedback & Recovery

> **Category**: UI/UX Design
> **Tags**: UX, Errors, Feedback

## Policy

```
Rule: Empathetic Error Handling
Description: Help users recover from errors instead of blaming them.
1. Contextual placement: Display validation errors next to the specific input field, not grouped indiscriminately at the top of the page.
2. Actionable copy: Error messages must state what went wrong AND how to fix it (e.g., "Password must contain a number" instead of "Invalid password").
3. Preserve input: Never wipe out a user's entire form submission if one field fails validation on the server.
4. Inline success: Use subtle toast notifications for successful background actions (e.g., "Settings saved") so users feel confident their actions registered.
5. Empty states: Provide illustrations or helpful descriptions and a clear "Call to Action" when a list or table is empty.
```
