# Visual Hierarchy Rules

> **Category**: UI/UX Design
> **Tags**: Design, Layout, Typography

## Policy

```
Rule: Clear Visual Hierarchy
Description: The most important element must draw the eye first.
1. Typography scales: Use only 3-4 font sizes on a screen. Distinguish hierarchy by font weight, not just size.
2. Primary Actions: A screen should have exactly one prominent primary action button. Secondary actions should use outlined, phantom, or ghost styles.
3. Proximity: Elements related to each other must be closer together than elements that are unrelated. Check your whitespace.
4. Readability: Cap text line lengths to 60-75 characters. Use minimum 150% line height for body text.
5. Contrast: Ensure important text achieves a high contrast ratio against its background. Dim non-essential metadata.
```
